SISTEMA DE APRENDIZAJE FEDERADO CON CLIENTES ANDROID PARA EL ANÁLISIS DE PARÁMETROS DE COMUNICACIÓN.

El uso de modelos de aprendizaje automático y redes neuronales es cada vez más habitual en aplicaciones reales, pero su entrenamiento requiere un alto coste computacional y, en muchos casos, la centralización de datos potencialmente sensibles. Al mismo tiempo, existe una enorme cantidad de dispositivos móviles con capacidad de cómputo que podrían colaborar en estos procesos de forma distribuida.
El aprendizaje federado propone un enfoque en el que múltiples dispositivos entrenan localmente un modelo y solo comparten actualizaciones con un servidor central, evitando así la transferencia de datos privados. En este tipo de sistemas, el interés no reside tanto en la complejidad del modelo como en el diseño del sistema distribuido: cómo se coordinan los nodos, qué información se intercambia, con qué frecuencia y cómo afectan las limitaciones de la red al proceso de entrenamiento.

Este proyecto plantea el diseño e implementación de un sistema práctico de aprendizaje federado compuesto por una aplicación Android que actúe como cliente y un servidor central encargado de la agregación de modelos. A partir de esta implementación, se estudiará el impacto de distintos parámetros de comunicación (frecuencia de envío, cuantización o compresión de actualizaciones, número de clientes por ronda, etc.) sobre la calidad del modelo entrenado y el coste de comunicación, poniendo el foco en arquitecturas distribuidas y eficiencia en redes.
