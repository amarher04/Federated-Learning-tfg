FEDERATED LEARNING SYSTEM WITH ANDROID CLIENTS FOR COMMUNICATION PARAMETER ANALYSIS.

The use of machine learning models and neural networks is increasingly common in real-world applications, but their training requires high computational costs and, in many cases, the centralization of potentially sensitive data. At the same time, there is a vast number of mobile devices with computing power that could collaborate on these processes in a distributed manner. Federated learning proposes an approach in which multiple devices locally train a model and only share updates with a central server, thus avoiding the transfer of private data. In this type of system, the focus is not so much on the complexity of the model as on the design of the distributed system: how the nodes are coordinated, what information is exchanged, how frequently, and how network limitations affect the training process.

This project proposes the design and implementation of a practical federated learning system composed of an Android application acting as a client and a central server responsible for model aggregation. Based on this implementation, the impact of different communication parameters (sending frequency, quantization or compression of updates, number of clients per round, etc.) on the quality of the trained model and the cost of communication will be studied, focusing on distributed architectures and network efficiency.
